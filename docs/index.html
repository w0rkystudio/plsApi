plsApi

Check Please! Demo için C# modlama API'si. Tek satırla oyun ekranının sol üstüne yazı bas (print_game), sadece LogOutput.log dosyasına kayıt düş (print_log), kendi sprite'ı ve ismiyle menüye yeni yemekler ekle (Foods) ya da animasyonlu, oturma tercihleri olan yeni müşteriler getir (Customers). A C# modding API for Check Please! Demo. Print text to the top-left of the game screen in one line (print_game), write a line only to LogOutput.log (print_log), add new dishes with their own sprite and name (Foods), or bring in new animated customers with their own seat preferences (Customers).

  • plsApi.dll v1.3.0
  • BepInEx 5.4.23
  • Unity 6000.5 · Mono
  • netstandard2.1

Elle kurmak istersenSetting it up by hand

Yeni bir klasör aç (ör. MyMod) ve içine aşağıdaki proje dosyasını koy. Oyun başka bir yerdeyse sadece GameDir satırını değiştir.

Make a new folder (e.g. MyMod) and put the project file below inside it. If the game is installed somewhere else, change only the GameDir line.

Visual Studio kullanıyorsan: "Sınıf Kitaplığı (.NET Framework)" şablonunu seçme. O şablon eski bir proje dosyası yapar ve genelde .NET Framework 3.5/4.x hedefler; plsApi ve oyunun DLL'leri o projede okunamaz, her şey kırmızı çizilir. Bunun yerine "Sınıf Kitaplığı" (.NET) şablonuyla proje aç, sonra oluşan .csproj dosyasının tüm içeriğini silip yukarıdaki kodu yapıştır ve AssemblyName kısmını kendi mod adınla değiştir.

Using Visual Studio? Do not pick the "Class Library (.NET Framework)" template. It creates an old-style project that targets .NET Framework 3.5/4.x, which can't read plsApi or the game's DLLs, so everything gets a red underline. Create the project with the "Class Library" (.NET) template instead, then replace the whole .csproj with the code above and change AssemblyName to your mod's name.

Neden netstandard2.1? Oyunun Unity sürümü (6000.5, Mono) .NET Standard 2.1 kütüphanelerini doğrudan yükler. Private=false ise oyunun kendi DLL'lerinin mod klasörüne kopyalanmasını engeller.

Why netstandard2.1? The game's Unity version (6000.5, Mono) loads .NET Standard 2.1 libraries directly. Private=false stops the game's own DLLs from being copied next to your mod.

05print_game

Ekranın sol üst köşesine mesaj yazar. Mesajlar alt alta dizilir, süreleri dolunca yarım saniyede solarak kaybolur. Unity zengin metin etiketleri (<b>, <i>, <color=...>, <size=...>) desteklenir.

Writes a message in the top-left corner of the screen. Messages stack downwards and fade out over half a second when their time is up. Unity rich text tags (<b>, <i>, <color=...>, <size=...>) work.

Sayılar ve değişkenlerNumbers and variables

message parametresi object olduğu için sayı, bool, vektör, her şeyi gönderebilirsin; ToString() kullanılır. null gönderirsen ekranda null yazar.

The message parameter is an object, so you can pass numbers, bools, vectors, anything; ToString() is used. Passing null prints null.

Süre ne zaman başlar? Mesajın süresi, ekranda ilk göründüğü kareden itibaren sayılır. Oyun açılırken (ilk kare yaklaşık 9 sn sonra gelir) Awake içinde yazdığın mesajlar kaybolmaz. Oyun duraklatılsa bile (Time.timeScale = 0) geri sayım devam eder. Aynı anda en fazla 12 mesaj görünür; fazlası gelince en eskisi silinir.

When does the timer start? A message's duration counts from the first frame it is drawn. Messages you send in Awake while the game is still loading (the first frame arrives about 9 s in) are not lost. The countdown keeps running while the game is paused (Time.timeScale = 0). At most 12 messages show at once; the oldest is dropped when a new one arrives.

06print_log

Mesajı yalnızca BepInEx\LogOutput.log dosyasına yazar. Ekranda görünmez, BepInEx konsoluna da gitmez. Satırın başına modunun adı otomatik eklenir ([BepInPlugin] içindeki isim).

Writes the message only to BepInEx\LogOutput.log. It doesn't show on screen and doesn't go to the BepInEx console. Your mod's name (the one in [BepInPlugin]) is added to the start of the line automatically.

LogOutput.log içinde böyle görünür:

In LogOutput.log it looks like this:

print_game

Oyuncunun görmesi gereken şeyler: bildirimler, sayaçlar, "mod açık" mesajı.

Things the player should see: notifications, counters, a "mod enabled" message.

print_log

Senin görmen gereken şeyler: hata ayıklama, değer takibi, hangi kodun çalıştığı.

Things you need to see: debugging, tracking values, which code ran.

Her print_log çağrısı dosyaya hemen yazılır, oyunu kapatmadan dosyayı açıp okuyabilirsin. BepInEx.cfg içinde disk log'u kapatılmışsa mesajlar BepInEx\plsApi.log dosyasına gider.

Each print_log call is written to the file right away, so you can open it while the game is running. If disk logging is turned off in BepInEx.cfg, messages go to BepInEx\plsApi.log instead.

07Özel yemeklerCustom foods

Foods.Register menüye yeni bir yemek ekler. Yemek her haritada baştan açık olur; sipariş balonunda, pastada, garsonun elinde ve almanakta kendi sprite'ı ve ismiyle görünür. Müşteriler onu oyunun kendi yemekleri gibi seçer: ırklarının sevdiği malzemeler şansı artırır, sevmedikleri azaltır, alerjisi olanlar kendi başına asla sipariş etmez.

Foods.Register adds a new dish to the menu. It is available from the start on every map and shows with its own sprite and name in the order bubble, on the pass, in the waiter's hands and in the almanac. Customers pick it like the game's own dishes: ingredients their race likes raise the odds, disliked ones lower them, and customers who are allergic never order it on their own.

1. Sprite'ı hazırla1. Prepare the sprite

  • Arka planı şeffaf bir PNG (JPG de olur ama şeffaf olmaz).
  • Kare olsun; 256×256 piksel yeterli. plsApi sprite'ı oyunun kendi yemekleriyle aynı boyuta ölçekler, çözünürlük önemli değil. Daha büyük ya da küçük istersen SpriteScale kullan.
  • Projende bir sprites klasörüne koy ve .csproj dosyasına aşağıdaki satırları ekle; derleyince DLL'in yanına kopyalanır.
  • A PNG with a transparent background (JPG works too, without transparency).
  • Make it square; 256×256 pixels is plenty. plsApi scales the sprite to the same size as the game's own dishes, so resolution doesn't matter. Use SpriteScale to make it bigger or smaller.
  • Put it in a sprites folder in your project and add the lines below to your .csproj; building copies it next to your DLL.
BepInEx\plugins\ └─ MyMod\ ├─ MyMod.dll └─ sprites\ ├─ pizza.png └─ lemonade.png

2. Yemeği kaydet2. Register the dish

Pluginin Awake metodunda bir CustomFood oluştur ve Foods.Register'a ver. Sadece kimlik, isim ve sprite zorunlu; geri kalan her şeyin varsayılan değeri var.

In your plugin's Awake, create a CustomFood and pass it to Foods.Register. Only the id, name and sprite are required; everything else has a default.

Müşteri neyi sipariş eder? Her ırkın sevdiği, sevmediği ve alerjik olduğu malzeme/tür listesi var. Oyun menüdeki her yemeğe bir ağırlık verir: sevilen her etiket ağırlığı artırır, sevilmeyen her etiket azaltır, alerji sıfırlar. Sonra rastgele seçer. plsApi bu ağırlığı Popularity ile çarpar. Yani malzeme seçimin, yemeğini kimin sipariş edeceğini belirler.

What do customers order? Each race has lists of liked, disliked and allergen ingredients/kinds. The game gives every dish on the menu a weight: each liked tag raises it, each disliked tag lowers it, an allergy sets it to zero. Then it picks at random. plsApi multiplies that weight by Popularity. So your ingredient choice decides who orders your dish.

Olaylar: sipariş ve servisEvents: ordered and served

Test etmekTesting

Müşterinin yemeğini seçmesini beklemek uzun sürebilir. Foods.ForceNextOrder ile sıradaki müşteriye (alerjisi yoksa) istediğin yemeği sipariş ettirebilirsin; oyunun kendi yemek kimlikleriyle de çalışır.

Waiting for a customer to pick your dish can take a while. Foods.ForceNextOrder makes the next customer (if not allergic) order the dish you want; it works with the game's own dish ids too.

Tam örnek: PizzaModFull example: PizzaMod

Dikkat: Sprite oyun açılırken yüklenir. Yol yanlışsa ya da dosya bozuksa yemek eklenmez ve LogOutput.log'a plsApi.Foods kaynağıyla hata yazılır. Aynı Id'yi iki kez kaydetmek hata fırlatır; oyundaki bir yemeğin kimliğini kullanırsan yemek atlanır.

Heads up: the sprite is loaded when the game starts. If the path is wrong or the file is broken, the dish is not added and an error tagged plsApi.Foods is written to LogOutput.log. Registering the same Id twice throws; using the id of one of the game's dishes skips your dish.

Dil kodları: en, tr, de, fr, es, es-419, pt-BR, pt-PT, pl, ru, zh-Hans, zh-Hant, ja, ko. Kayıt dosyası yemek kimliği saklamadığı için modu sonradan kaldırmak kayıtları bozmaz.

Language codes: en, tr, de, fr, es, es-419, pt-BR, pt-PT, pl, ru, zh-Hans, zh-Hant, ja, ko. The save file doesn't store dish ids, so removing a food mod later doesn't break saves.

08Özel müşterilerCustom customers

Customers.Register restorana yeni bir müşteri türü ekler (oyunun dilinde yeni bir "ırk"). Bu müşteriler sıraya girer, oturur, sipariş verir, yer ve öder; tıpkı oyunun kendi müşterileri gibi. Neyi sipariş edecekleri sevdikleri, sevmedikleri ve alerjileri olan malzemelere göre belirlenir. Pencere ya da şarkıcı yanında oturmayı ne kadar istediklerini haritaya ve yıldıza göre şanslarıyla birlikte ayarlayabilirsin.

Customers.Register adds a new kind of customer to the restaurant (a new "race" in the game's terms). They queue, sit, order, eat and pay just like the game's own customers. What they order follows the ingredients they like, dislike and are allergic to. How much they want a window seat or a seat by the singer can be set per map and star level, each with its own chance.

İki çizim yoluTwo ways to draw them

Tek spriteSingle sprite

Karakterin tamamı tek bir PNG'de. Animasyon tüm resmi sallayarak, yaylandırarak yapılır. En hızlı yol.

The whole character in one PNG. Animation bobs and sways the whole picture. The quickest way.

Kollar ayrıSeparate arms

Kolsuz gövde + kol PNG'leri. Yürürken ve yemek yerken kollar ayrıca sallanır. Omuz noktalarını piksel olarak verirsin.

A body without arms + arm PNGs. The arms swing on their own while walking and eating. You give the shoulder points in pixels.

  • Şeffaf PNG, karakter sağa bakıyor ve ayakları resmin alt kenarına değiyor olsun. Çözünürlük önemli değil: plsApi karakteri AnimationsFrom ırkıyla aynı boya ölçekler (Scale ile değiştirebilirsin).
  • Kol: aşağı sarkan halde çiz, omuz resmin üst ortasında olsun, gövdeyle aynı piksel ölçeğinde.
  • Omuz koordinatları gövde resminde sol üst köşeden piksel olarak ölçülür. Vermezsen AnimationsFrom ırkının oranları kullanılır.
  • Animasyonlar (yürüme, oturma, yeme) AnimationsFrom ile seçtiğin oyun ırkından ödünç alınır.
  • A transparent PNG with the character facing right and feet touching the bottom edge. Resolution doesn't matter: plsApi scales the character to the height of the AnimationsFrom race (change it with Scale).
  • Arms: draw them hanging down with the shoulder at the top centre of the image, at the same pixel scale as the body.
  • Shoulder coordinates are pixels in the body image, measured from the top-left corner. Leave them out to use the proportions of the AnimationsFrom race.
  • Animations (walk, sit, eat) are borrowed from the game race you pick with AnimationsFrom.

Oturma tercihleri ve şansSeat preferences and chance

Her SeatRule "bu müşteri %Chance ihtimalle Spot'u Feeling" demektir. İstersen sadece bir haritada (MapId) ve bir yıldız aralığında (MinStar/MaxStar) geçerli olur. Müşteri gelince kurallar sırayla denenir; zarı tutan ilk kural kazanır. Hiçbiri tutmazsa tercihi olmaz (SeatRulesReplaceGame = false yaparsan oyunun kendi rastgele tercihi kalır).

Each SeatRule means "with Chance probability this customer Feeling the Spot". It can be limited to one map (MapId) and a star range (MinStar/MaxStar). When the customer arrives, the rules are tried in order and the first one whose roll succeeds wins. If none does, they have no preference (set SeatRulesReplaceGame = false to keep the game's own random preference instead).

The game still applies its own rules: the singer rule is skipped on maps without a live stage, a rule is skipped when the room has no fitting seat, and for groups the game sometimes gives everyone the group leader's preference.

Komşular: kiminle anlaşır, kiminle kavga ederNeighbours: who they get on with, who they fight

Neighbors sözlüğüne diğer müşterileri ve bir seviye yaz. Anahtar oyunun ırk adı ("Elf", "Orc"…) ya da başka bir mod müşterisinin kimliği ("ghost") olabilir. Etkisi, aynı masaya oturduklarında görülür.

Put other customers and a level into the Neighbors dictionary. The key can be a game race name ("Elf", "Orc"…) or another mod customer's id ("ghost"). It takes effect when they sit at the same table.

SeviyeLevelMasada ne olurWhat happens at the tableKitaptaIn the book

NeighborsMutual = true (varsayılan) ise karşı taraf da aynı şekilde hisseder; o taraf kendi ilişkisini yazmışsa onunki geçerlidir. Aynı grupla gelenler birbiriyle kavga etmez ve kavga edecek seviyedekiler aynı grupla gelmez. Oyunun kendi kuralıyla olumsuz komşular %25 şansla kavga ederdi; mod ilişkilerinde bu şans yerine yukarıdaki seviyeler geçerlidir.

With NeighborsMutual = true (the default) the other side feels the same way back; if it wrote its own relation, that one wins. Customers in the same group never fight each other, and customers at fight level never arrive in the same group. The game's own rule makes negative neighbours fight with a 25% chance; for mod relations the levels above decide instead.

Kitaptaki MOD sekmesiThe MOD tab in the book

Oyun içinde karakter defterini (almanak) açınca mavi ırk sekmesinin yanında altın renkli bir MOD sekmesi çıkar. Ona tıklayınca sol sayfada mod müşterilerinin ikonları, sağ sayfada seçilenin adı, açıklaması, kaç kez karşılaşıldığı, komşu tercihleri (kalp / halka / çarpı / kırık kalp sütunlarında) ve alerji / sever / sevmez yemekleri görünür. Bu sayfa modunu kontrol etmen için olduğundan bilgiler keşfedilmeyi beklemeden hepsi gösterilir. 12'den fazla müşteride sayfalar < > ile değişir.

Open the character book (almanac) in game and a gold MOD tab appears next to the blue species tab. Clicking it shows your mod customers' icons on the left page, and on the right the selected one's name, description, how many times you've met them, neighbour preferences (in the heart / ring / cross / broken-heart columns) and their allergen / like / dislike foods. The page is meant for checking your mod, so everything is shown without waiting to be discovered. With more than 12 customers, < > switch pages.

12Sorun gidermeTroubleshooting

BepInPlugin, BaseUnityPlugin, print_game kırmızı çiziliyor

Proje büyük ihtimalle Visual Studio'nun ".NET Framework" şablonuyla açıldı (.csproj içinde TargetFrameworkVersion v3.5 ya da Compile Include satırları görürsün). .csproj dosyasının içeriğini 3. adımdaki şablonla değiştir. Projede Properties\AssemblyInfo.cs varsa <PropertyGroup> içine <GenerateAssemblyInfo>false</GenerateAssemblyInfo> ekle. Sonra Visual Studio'da projeye sağ tıklayıp Projeyi Yeniden Yükle de.

Ekranda hiçbir şey çıkmıyor

  • LogOutput.log içinde plsApi v1.3.0 loaded satırı var mı? Yoksa plsApi.dll yanlış klasörde.
  • Modun yüklendi mi? Loading [MyMod 1.0.0] satırını ara.
  • Süreyi çok kısa verdiysen (ör. 0.2f) mesaj göz açıp kapayıncaya kadar kaybolur.

Derleme hatası: CS0012 'MonoBehaviour' ... UnityEngine

UnityEngine.dll referansı eksik. 3. adımdaki proje dosyasında hem UnityEngine hem UnityEngine.CoreModule olmalı.

Derleme hatası: plsApi bulunamadı

Proje, plsApi.dll'i BepInEx\plugins\plsApi\ içinde arar. Önce 2. adımı yap ya da HintPath yolunu düzelt.

Input.GetKeyDown hata veriyor

Oyun yeni Input System kullanıyor; eski Input sınıfı çalışmayabilir. 9. adımdaki Keyboard.current yöntemini kullan.

Özel yemeğim menüde yok ya da kimse sipariş etmiyor

  • LogOutput.log'da plsApi.Foods satırlarına bak: Registered custom food var mı, sprite hatası var mı?
  • Sprite yolu DLL klasörüne göredir: plugins\MyMod\sprites\pizza.png gerçekten orada mı?
  • MapId verdiysen yemek sadece o haritada çıkar. Popularity = 0 ise müşteri kendi seçmez.
  • Malzemeler o haritadaki ırkların alerjisine denk geliyorsa sipariş edilmez. F9 + ForceNextOrder ile dene.

Özel müşterim hiç gelmiyor

  • LogOutput.log'da plsApi.Customers satırlarına bak: Built customer var mı, sprite hatası var mı?
  • FirstMapId/FirstStar verdiysen o haritaya ve yıldıza gelmeden çıkmaz. SpawnWeight = 0 ise sadece ForceNextCustomer ile gelir.
  • Plaj haritalarında sadece OnBeachMaps = true olanlar gelir.
  • Hemen görmek için Customers.ForceNextCustomer("id") kullan.

Müşteri havada ya da yerin içinde duruyor

Resimde ayaklar alt kenara değmiyor demektir. Alttaki boşluğu kırp. Kollar yanlış yerdeyse LeftShoulder/RightShoulder değerlerini resmin sol üst köşesinden ölç.

print_log konsolda görünmüyor

Bu bilerek böyle. Konsolda da görmek istersen BepInEx'in kendi log'unu kullan: Logger.LogInfo("...").

BepInPlugin, BaseUnityPlugin, print_game are underlined in red

The project was most likely made with Visual Studio's ".NET Framework" template (the .csproj has TargetFrameworkVersion v3.5 or Compile Include lines). Replace the .csproj contents with the template from step 3. If the project has Properties\AssemblyInfo.cs, add <GenerateAssemblyInfo>false</GenerateAssemblyInfo> inside the <PropertyGroup>. Then right-click the project in Visual Studio and choose Reload Project.

Nothing shows on screen

  • Is there a plsApi v1.3.0 loaded line in LogOutput.log? If not, plsApi.dll is in the wrong folder.
  • Did your mod load? Look for Loading [MyMod 1.0.0].
  • A very short duration (e.g. 0.2f) makes the message disappear almost instantly.

Build error: CS0012 'MonoBehaviour' ... UnityEngine

The UnityEngine.dll reference is missing. The project file from step 3 needs both UnityEngine and UnityEngine.CoreModule.

Build error: plsApi not found

The project looks for plsApi.dll in BepInEx\plugins\plsApi\. Do step 2 first, or fix the HintPath.

Input.GetKeyDown throws an error

The game uses the new Input System, so the old Input class may not work. Use Keyboard.current as in step 9.

My custom dish isn't on the menu, or nobody orders it

  • Check the plsApi.Foods lines in LogOutput.log: is there a Registered custom food line, or a sprite error?
  • The sprite path is relative to your DLL folder: is plugins\MyMod\sprites\pizza.png really there?
  • With a MapId the dish only appears on that map. With Popularity = 0 customers never pick it themselves.
  • If the ingredients match the allergies of the races on that map, they won't order it. Try F9 + ForceNextOrder.

My custom customer never shows up

  • Check the plsApi.Customers lines in LogOutput.log: is there a Built customer line, or a sprite error?
  • With FirstMapId/FirstStar they only appear from that map and star level. With SpawnWeight = 0 they only come via ForceNextCustomer.
  • On beach maps only customers with OnBeachMaps = true come.
  • Use Customers.ForceNextCustomer("id") to see them right away.

The customer floats or sinks into the floor

The feet don't touch the bottom edge of the image. Crop the empty space below them. If the arms are in the wrong place, measure LeftShoulder/RightShoulder from the top-left corner of the image.

print_log doesn't show in the console

That is on purpose. If you also want console output, use BepInEx's own logger: Logger.LogInfo("...").
